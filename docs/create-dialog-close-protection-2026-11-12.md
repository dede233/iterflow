# 新增反馈与需求关闭保护（2026-11-12）

用户反馈误按 Esc 导致新增弹窗关闭，授权本地修复。基于 `521b3db` 开发；本轮不部署 TEST/正式，不推送或合并，不连接数据库。

## 行为

- 新增反馈、新建需求通过 Esc、右上角关闭或取消退出时统一先确认。空表单显示“确认关闭？”，有修改显示“放弃未保存的修改？”。
- 选择“继续编辑”保留原表单；明确确认后才关闭。确认框不响应 Esc，连续误触不会跳过提示或叠加多个确认框。
- 反馈草稿保护覆盖文本、业务系统、类型/紧急程度、接收人和待上传附件；独立新建页也增加未保存离开/刷新保护。
- 提交期间禁用关闭、取消及重复提交；提交失败保留草稿，成功提交后正常关闭/跳转，无多余确认。
- 复用现有 `useUnsavedChanges`，不新增持久化草稿或后端接口。已有共享未保存确认框同样不通过 Esc 关闭，按钮和右上角关闭仍可返回编辑。
