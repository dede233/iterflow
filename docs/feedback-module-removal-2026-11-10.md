# 反馈界面移除模块 · 2026-11-10

用户指出提交反馈仍显示已弃用的“所属模块”。本次依据 ui-ux-pro-max 的表单分组、响应式与一致性准则补齐所有反馈入口，仅本地修改前端。

## 修改

- 提交反馈整页及弹窗移除所属模块，所属系统占满原两列表单的一行；不再保存模块选择状态或提交 module_id。
- 编辑反馈、整页/抽屉详情移除所属模块。
- 桌面筛选栏及手机筛选抽屉移除模块筛选；应用查询、分页和返回列表链接不再使用旧 module_id 参数。旧 URL 初次读取时直接忽略该参数，后续应用筛选会生成规范 URL，防止不可见筛选。
- 普通编辑不发送 system_id/module_id，保留已有历史关联，也不触发旧停用模块的重新校验。仅实际修改/清空所属系统时发送新 system_id 和 module_id=null，避免跨系统残留旧模块。revision 和冲突处理不变。
- 保留后端字段、接口、历史模块数据和审计记录；不修改 API 契约、数据库或迁移，不删除历史数据。API 文档/审计中的历史“模块”术语保留，不是可操作的业务模块入口。
