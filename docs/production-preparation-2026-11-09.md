- **DDL 已启动/部分失败**：MySQL DDL 不原子，保持停写并保留现场；检查实际 head、列/FK/触发器/数据和回执，优先前向修复。不能自动重跑、stamp、降级或将旧应用直接接回部分迁移库。

- **仅 Web 故障**：仅可使用已验证兼容当前 API/schema/归属/公告读取规则的 Web 产物，保留新 API/worker/数据库，不能默认回旧正式 Web。
