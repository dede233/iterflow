## 复现与修复

| 位置 | 原因与实测 | 修复 |
| --- | --- | --- |
| 版本需求清单操作 | 批量按钮 32px，添加按钮因 small 为 24px | 同组统一默认尺寸及 8px 间距 |
| 清单筛选 | grid 居中对齐包含标签的整个表单项，重置按钮高出输入框底边 15px | 按控件底边对齐；移动端输入和按钮至少 44px |
| 共享卡片标题操作区 | 标题和操作缺少充分的收缩、换行约束 | 标题保留可读宽度，按钮居中、窄屏自动换行，移动端按钮至少 44px |
| 页头与弹窗/抽屉底栏 | 混合链接、按钮缺少统一垂直对齐 | 操作区域按中心对齐 |
| 需求摘要底栏 | 链接 padding 和额外 margin 导致中心差 4.5px、间距 20px | 链接与按钮同高，间距恢复 8px |
| 编辑表单、审计筛选 | flex gap 与 Element Plus 相邻按钮 margin 叠加 | 移除重复 margin |

同时检查共享 PageHeader、SectionCard、ListFilterPanel、编辑操作区、审计筛选和弹窗底栏。普通列表筛选使用行内标签，没有清单筛选的同类底边问题，保留原布局。

上一轮检查侧重可见性和横向溢出，未断言按钮等高及输入框底边一致，因此漏掉了本次错位。现在新增实际 bounding rectangle 检查，并在全页面响应式回归中检查操作区居中、边界及重叠。
