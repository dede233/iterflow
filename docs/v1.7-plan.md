# IterFlow V1.7 — Approved Scope & Phase Plan

> 范围冻结：2026-10-02，用户 Autonomous Development & Self-Review Directive 已批准 C0/C1/C2/C3/C6/C8/C9 和 Phase 0–4。开发基线为正式 v1.6.0 `f0aa8475ff081fc963cdd08045d23e383a3c594e`；审计见 [Baseline Audit](v1.7-baseline-audit.md)，执行证据见 [Execution Log](v1.7-autonomous-execution-log.md)。本计划仅定义增量，不能改变AGENTS的领域、安全和事务规则。

## 1. 已冻结的硬边界

- Feedback→Requirement→Version→Publish→Release；Publish唯一正式发布入口，Release record-only/SUCCESS；集中状态机、原子事务、revision CAS/409、RBAC/DataScope不变。
- Hash Router `createWebHashHistory(import.meta.env.BASE_URL)`、`/#/...`和五视口验收保持。
- v1.6.0 annotated tag `0130932d1b6e2aa42e61a09d64917727259414e0` / 解引用上述commit不可移动；v1.5.0历史发布不可变。
- Preview `33d36d78ab4bedf48835d124f295f1ca8c352eae`是正式版本+部署配置，V1.7禁止从Preview开发；本轮不部署、不整分支反向merge。
- 首次audit仅新增两文档；获授权后Phase0最小校准入口/TASKS/状态机文字与本计划，无产品代码或部署改动。
- 涉及基础原则改变的候选必须标 **ARCHITECTURE DECISION REQUIRED**，在专项决策前不能排入开发。

优先级定义：P0事实错误/已发布错标/正确性；P1已有延期项或高频协作、低架构风险；P2组织架构或基础设施扩展。优先级不表示批准。初始评估保留审计依据；用户已正式批准 C0/C1/C2/C3/C6/C8/C9（APPROVED），C4删除/C5/C7为DEFER。

明确外部基础设施失败允许同HEAD重跑失败job一次，保留attempt1证据，再失败HARD STOP；真实代码/test失败不能靠rerun。不得减assertion、skip失败测试、增加固定sleep、禁用门禁。
