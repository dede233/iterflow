# IterFlow V1.7 — Candidate Backlog & DRAFT Scope

> Phase 0，2026-10-02，等待独立终审。产品开发基线：master / released v1.6.0 `f0aa8475ff081fc963cdd08045d23e383a3c594e`。审计证据见 [Baseline Audit](v1.7-baseline-audit.md)。本文件不替代AGENTS、批准的领域规则、TASKS或现有契约；所有需求和阶段均为草案，尚未冻结产品范围。

## 1. 已冻结的硬边界

- Feedback→Requirement→Version→Publish→Release；Publish唯一正式发布入口，Release record-only/SUCCESS；集中状态机、原子事务、revision CAS/409、RBAC/DataScope不变。
- Hash Router `createWebHashHistory(import.meta.env.BASE_URL)`、`/#/...`和五视口验收保持。
- v1.6.0 annotated tag `0130932d1b6e2aa42e61a09d64917727259414e0` / 解引用上述commit不可移动；v1.5.0历史发布不可变。
- Preview `33d36d78ab4bedf48835d124f295f1ca8c352eae`是正式版本+部署配置，V1.7禁止从Preview开发；本轮不部署、不整分支反向merge。
- Phase0只新增audit与plan。没有产品代码、migration、OpenAPI、permission、package、CI、Preview改动，没有修改六入口文档或TASKS。
- 涉及基础原则改变的候选必须标 **ARCHITECTURE DECISION REQUIRED**，在专项决策前不能排入开发。

优先级定义：P0事实错误/已发布错标/正确性；P1已有延期项或高频协作、低架构风险；P2组织架构或基础设施扩展。优先级不表示批准。Decision仅使用PROPOSED、DEFER、REQUIRES PRODUCT DECISION、REQUIRES ARCHITECTURE DECISION；没有APPROVED条目。

## 5. 非范围与后续决策

明确不自动纳入：工时/Story Point/预计开发时长/报表、AI自动改状态、Release rollback workflow、状态机/Publish事务变化、微服务、独立Mobile App、Feedback直接加入Version、WebSocket平台、SSE/message broker、Dashboard暴露operator/before/after/IP/UA、权限兼容码自动升级、数据库无证据重构。

产品决策：主题与容量；C3是否接受wildcard兼容变化；C2按精确时间还是本地日期、闭/开区间/精度；C6刷新SLA与focus/poll选择；C9是否纳入；TEAM是否有实际价值。Version name/notes/publisher/result不自动加入。
